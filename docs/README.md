# Mindclade Documentation

Architecture sources, accepted ADRs, engineering standards, developer guides,
security controls, and operational evidence are versioned with the behavior
they govern.

Wave 0 activates only architecture/governance documentation. Product-domain
guides, runbooks, model cards, dataset cards, and examples remain absent until
their owning capability exists and has executable evidence.

Humans edit the ordered files under `architecture/blueprint/` and the
machine-readable manifests. Generated architecture is a deterministic review
artifact and is never edited directly.
