# Internal console control-plane integration

This package is a private, unpublished server-side data source for the Mindclade console. It consumes only `@mindclade/internal-sdk`: generated transports stay behind that SDK, and PostgreSQL, Pub/Sub, and GCS remain inaccessible service-side capabilities.

The current bounded surface lists, reads, cancels, and watches durable operations and resolves/downloads content-addressed artifacts. The SDK owns workload identity, TLS, tenant expectations, deadlines, retries, idempotency, pagination, error normalization, stream resumption, and digest validation. Browser bundles must call a server route backed by this module rather than receive workload credentials.

Listing goes through the SDK page type: `firstPage` returns one page with its opaque cursor and the serving request ID, `pages` walks the cursor, and `listAll` collects every item under the SDK's page and item budgets, which callers narrow with `limits`. The console never threads a page token, counts pages, retries, or re-parses a gRPC status: failures reach callers as SDK error classes (`ValidationError`, `AuthorizationError`, `CancelledError`, `TransportError`, ...) carrying their stable codes. The one exception is a client-side deadline, which the TypeScript SDK raises as the base `MindcladeError` (`kind` `deadline_exceeded`, `stableCode` `unclassified`) because it publishes no deadline class; that case is discriminated on `kind` until the SDK gains one.

`resolveAndDownload` is the one place the console holds bytes itself, because the SDK's verified-download helper publishes to a file and the console needs an in-memory response body. Its default ceiling is the SDK's published `MAX_MESSAGE_BYTES`; the SDK still owns chunk digests, offsets, terminal size, and full-digest verification.
